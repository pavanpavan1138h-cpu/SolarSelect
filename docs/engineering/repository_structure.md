# Repository Structure — SolarSelect

This document details the complete physical directory hierarchy of the SolarSelect repository, defining the specific responsibilities of each directory, script, notebook, and artifact.

---

## 1. Directory Tree Map

```text
SolarSelect/
├── configs/                             # Configuration, Schemas & Catalogue Files
│   ├── panels_catalogue_schema.json     # Canonical 43-column PV panel JSON schema
│   ├── panels_catalogue_template.csv   # Header-only CSV template for catalogue data
│   └── panels_catalogue.csv            # Active catalogue file (3 unverified baseline records)
│
├── data/                                # Data Storage (Git/DVC Governed)
│   ├── raw/                             # Immutable raw data archives
│   │   ├── archive/                     # Kaggle Plant 1 & Plant 2 generation/weather CSVs
│   │   ├── unisolar/                    # UNISOLAR generation, weather, and site CSVs
│   │   └── archive (2)/                 # Raw multi-year telemetry archive
│   ├── interim/                         # Intermediate plant aggregations & coverage subsets
│   └── processed/                       # ML-ready datasets generated by prepare_phase3_data.py
│       ├── unisolar/                    # Full Cohort (Dataset A: 24 sites) Train/Val/Test
│       │   ├── feature_dictionary.csv   # Authoritative 29 predictive features
│       │   ├── preprocessing_metadata.json # Split boundaries, imputation medians, counts
│       │   └── peer_cohort/             # Peer Cohort (Dataset B: 22 sites) Train/Val/Test
│       └── kaggle_benchmark/            # Processed Kaggle benchmark files
│
├── docs/                                # Central Technical Documentation Portal
│   ├── README.md                        # Documentation index & portal guide
│   ├── project/                         # Project overview, objectives, architecture, roadmap
│   ├── data/                            # Dataset inventory, dictionaries, governance, preprocessing
│   ├── machine_learning/                # ML targets, feature engineering, models, evaluations
│   ├── panel_catalogue/                 # Catalogue schema, inventory, validation rules, policy
│   ├── engineering/                     # Repository structure, environment, execution, reproducibility
│   ├── decisions/                       # ADRs, assumptions, limitations, and risk registers
│   └── reports/                         # Detailed chronological phase-wise history
│
├── models/                              # Serialized ML Model Artifacts & Metadata
│   ├── phase4/                          # Preserved Phase 4 experimental candidate models
│   │   ├── full_cohort/                 # Tuned ElasticNet & ExtraTrees
│   │   ├── peer_cohort/                 # Tuned ExtraTrees & ElasticNet
│   │   └── model_metadata.json          # Phase 4 CV metrics and hyperparameter configurations
│   └── phase5/                          # Final Phase 5 production models & evaluation metadata
│       ├── final/                       # Retrained models on combined pre-test data (Train+Val)
│       │   ├── full_cohort/             # final_elastic_net.joblib, final_extra_trees.joblib
│       │   └── peer_cohort/             # final_extra_trees.joblib, final_elastic_net.joblib
│       └── final_model_metadata.json    # Complete evaluation metadata, test metrics, and verdicts
│
├── notebooks/                           # Chronological Research & Execution Notebooks
│   ├── README.md                        # Master notebook directory guide
│   ├── data_inspection/                 # Phase 1: Raw dataset inspection & verification
│   ├── eda2.0/                          # Phase 2: Tasks 1–6 comprehensive EDA notebooks
│   ├── phase3/                          # Phase 3: Target definition & data preparation notebook
│   ├── phase4/                          # Phase 4: Baseline establishment & model development
│   ├── phase5/                          # Phase 5: Diagnostics, blending, and test generalization
│   └── phase6/                          # Phase 6: Catalogue inventory, schema & validation
│
├── reports/                             # Structured CSV/JSON Analytical Reports
│   ├── phase4/                          # Phase 4 CV metrics, test results, feature importance
│   ├── phase5/                          # Phase 5 diagnostics, blend curves, test evaluations
│   └── phase6/                          # Phase 6 catalogue validation report JSON
│
├── src/                                 # Production Python Scripts & Modular Pipelines
│   ├── prepare_phase3_data.py           # Phase 3 automated preprocessing pipeline
│   └── validate_panel_catalogue.py      # Phase 6 automated catalogue validation engine
│
├── .dvc/                                # Data Version Control configuration & remotes
├── log.txt                              # Authoritative chronological project execution audit trail
├── requirements.txt                     # Pinned Python package dependencies
└── README.md                            # Primary project landing page & quickstart
```
