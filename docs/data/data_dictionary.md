# Data Dictionary — SolarSelect

This document details the exact schemas, physical units, data types, and definitions across all raw, engineered, and catalogue datasets.

---

## 1. Raw Kaggle Generation Datasets (`Plant_1_Generation_Data.csv`, `Plant_2_Generation_Data.csv`)

| Column Name | Data Type | Physical Unit | Description & Engineering Notes |
|---|---|---|---|
| `DATE_TIME` | string | `DD-MM-YYYY HH:MM` (P1) / `YYYY-MM-DD HH:MM:SS` (P2) | Telemetry observation timestamp (15-minute interval). Standardized in preprocessing. |
| `PLANT_ID` | integer | categorical ID | Plant identifier: `4135001` (Plant 1), `4136001` (Plant 2). |
| `SOURCE_KEY` | string | alphanumeric ID | Inverter identifier (22 unique inverters per plant). |
| `DC_POWER` | float | kW | Inverter DC input power. Note: Plant 1 contains an observed $10\times$ DC/AC scale discrepancy relative to Plant 2. |
| `AC_POWER` | float | kW | Inverter AC output power. Real power delivered to substation. |
| `DAILY_YIELD` | float | kWh | Cumulative daily energy generated by inverter up to timestamp. Resets to 0 at midnight. Excluded from predictive features to prevent leakage. |
| `TOTAL_YIELD` | float | kWh | Monotonically increasing inverter lifetime energy counter. Excluded from predictive features to prevent leakage. |

## 4. Phase 3 Feature Matrix (`data/processed/unisolar/`)

The model matrix contains **33 columns**: 3 identifiers, 1 primary target, and **29 predictive features**.

### A. Identifiers & Target (4 columns)
1. `SiteKey` (int): Campus building identifier.
2. `Date` (string): Calendar date (`YYYY-MM-DD`).
3. `split` (string): Chronological partition label (`train`, `validation`, `test`).
4. **`target_daily_yield`** (float, $\text{kWh}/\text{kW}_p/\text{day}$): Primary target: $\frac{\sum_{i=1}^{96} E_{15\text{m}, i}}{\text{kW}_p}$.

### B. The 29 Authoritative Predictive Inputs
1. `kWp` (float, kWp): Nameplate DC capacity rating.
2. `day_of_year` (int, 1–366): Continuous day index within the calendar year.
3. `month` (int, 1–12): Calendar month index.
4. `is_weekend` (int, 0/1): Binary indicator of Saturday/Sunday.
5. `day_sin` (float, $[-1, 1]$): Cyclical encoding $\sin(2\pi \cdot \text{day\_of\_year} / 365.25)$.
6. `day_cos` (float, $[-1, 1]$): Cyclical encoding $\cos(2\pi \cdot \text{day\_of\_year} / 365.25)$.
7. `month_sin` (float, $[-1, 1]$): Cyclical encoding $\sin(2\pi \cdot \text{month} / 12)$.
8. `month_cos` (float, $[-1, 1]$): Cyclical encoding $\cos(2\pi \cdot \text{month} / 12)$.
9. `solar_noon_elevation_deg` (float, degrees): Solar noon altitude angle computed via astronomical formulas.
10. `daylight_hours` (float, hours): Theoretical astronomical photoperiod between sunrise and sunset.
11. `extraterrestrial_radiation_h0` (float, $\text{MJ}/\text{m}^2/\text{day}$): Theoretical daily extraterrestrial insolation on horizontal surface.
12. `lag1_temp_mean` (float, °C): Day-ahead mean ambient air temperature ($\tau \ge 24\text{h}$).
13. `lag1_temp_max` (float, °C): Day-ahead maximum ambient air temperature.
14. `lag1_temp_min` (float, °C): Day-ahead minimum ambient air temperature.
15. `lag1_temp_range` (float, °C): Day-ahead diurnal thermal swing (`temp_max - temp_min`).
16. `lag1_rh_mean` (float, %): Day-ahead mean atmospheric relative humidity.
17. `lag1_daily_yield` (float, $\text{kWh}/\text{kW}_p/\text{day}$): Day-ahead ($t-1$) specific yield. Persistence baseline input.
18. `lag2_daily_yield` (float, $\text{kWh}/\text{kW}_p/\text{day}$): 2-day-ahead ($t-2$) specific yield.
19. `lag7_daily_yield` (float, $\text{kWh}/\text{kW}_p/\text{day}$): 7-day-ahead ($t-7$) same-weekday specific yield.
20. `rolling_mean_7d_yield` (float, $\text{kWh}/\text{kW}_p/\text{day}$): 7-day backward moving average of specific yield ($t-7$ to $t-1$).
21. `rolling_std_7d_yield` (float, $\text{kWh}/\text{kW}_p/\text{day}$): 7-day backward moving standard deviation (inter-day volatility).
22. `rolling_mean_14d_yield` (float, $\text{kWh}/\text{kW}_p/\text{day}$): 14-day backward moving average of specific yield.
23. `rolling_mean_30d_yield` (float, $\text{kWh}/\text{kW}_p/\text{day}$): 30-day backward moving average capturing monthly baseline drift.
24. `temp_rolling_mean_7d` (float, °C): 7-day backward moving average of daily mean ambient temperature.
25. `rh_rolling_mean_7d` (float, %): 7-day backward moving average of daily mean relative humidity.
26. `has_valid_lag1` (int, 0/1): Binary indicator showing whether day $t-1$ telemetry was observed or imputed.
27. `has_valid_lag2` (int, 0/1): Binary indicator showing whether day $t-2$ telemetry was observed.
28. `has_valid_lag7` (int, 0/1): Binary indicator showing whether day $t-7$ telemetry was observed.
29. `has_valid_rolling7` (int, 0/1): Binary indicator showing whether full 7-day backward window was available.

## 5. Diagnostic Metadata Matrix (`diagnostic_metadata.csv`)

Contains **17 non-predictive variables** strictly quarantined from model training to prevent leakage:
- `valid_interval_count` (int): Number of non-null 15-minute generation intervals recorded in the day (typically 40–55).
- `core_valid_interval_count` (int): Number of non-null intervals during core solar hours (09:00–15:45, max 28). Required $\ge 26$.
- `core_window_completeness_pct` (float): Core window non-null percentage ($\ge 92.86\%$).
- `raw_daily_energy_kwh` (float, kWh): Absolute unnormalized daily energy sum ($\sum E_{15\text{m}}$).
- `capacity_factor_24h` (float, %): Effective 24-hour capacity factor: $\frac{\text{raw\_daily\_energy\_kwh}}{\text{kWp} \times 24} \times 100$.
- `flag_missing_telemetry` (int): Flag for days with incomplete intervals.
- `flag_high_yield_anomaly` (int): Flag for days where $Y_f > 10\text{ kWh}/\text{kW}_p/\text{day}$ (identifies Site 19).
- `flag_low_yield_anomaly` (int): Flag for clear days with near-zero yield (inverter tripping).
- Plus 9 supporting timestamp and site diagnostic indicators.
